# Live Streams Plugin for Firebot

This plugin adds a page to Firebot that shows all currently live streams running Firebot. Same stuff as the [featured streams page](https://firebot.app/watch).

## Prerequisites
- Firebot 5.67 or higher

## Setup

1. Download the [latest](https://github.com/zunderscore/firebot-plugin-live-streams/releases/latest) version of `firebot-live-streams.js`
1. Go to Tools > Plugin Manager in Firebot
1. Click "Install From File"
1. Select the `firebot-live-streams.js` you downloaded
